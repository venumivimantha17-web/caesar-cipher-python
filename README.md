# Caesar Cipher

A simple Python implementation of the Caesar Cipher encryption technique.

## Description

This project implements a Caesar Cipher that can encrypt and decrypt messages by shifting letters through the alphabet by a specified number of positions.

The program includes:
- Input validation for the shift value
- Encryption of uppercase and lowercase letters
- Decryption using the reverse shift
- Separate `encrypt()` and `decrypt()` functions
- Support for shifts from 1 to 25
